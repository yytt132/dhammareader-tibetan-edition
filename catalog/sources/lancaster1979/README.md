# lancaster1979

- Source: Lewis R. Lancaster with Sung-bae Park, The Korean Buddhist Canon: A Descriptive Catalogue (Berkeley: University of California Press, 1979)
- Rights: in copyright; only bibliographic facts are used (number correspondences, titles, translator names)
- Used for: Tohoku -> Koryŏ (K) -> Taishō (T) correspondences; Koryŏ titles as printed in the catalogue
- Files: chinese_parallels.tsv

This folder holds only data derived from this source and can be removed on its own (one commit) if the rights holder asks. The main catalogue files do not depend on it.
